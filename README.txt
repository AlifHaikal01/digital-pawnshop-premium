DIGITAL PAWNSHOP MANAGEMENT SYSTEM — PREMIUM GITHUB PAGES PROTOTYPE

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Install Live Server by Ritwick Dey.
4. Right-click index.html -> Open with Live Server.

PUBLISH TO GITHUB PAGES
1. Create a GitHub repository, e.g. digital-pawnshop.
2. Upload all extracted contents. index.html must be at repository root.
3. Commit changes.
4. Settings -> Pages.
5. Source: Deploy from a branch.
6. Branch: main.
7. Folder: / (root).
8. Save and wait for GitHub to publish.

DEMO
Public -> Login -> choose Customer, Pawn Valuation Officer, or Finance & Risk Officer.

Front-end presentation prototype only; no real database, uploads, or payments.
